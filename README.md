The World in One Day — the world news of Thursday 19 November 2026 in one image, built for make.fun's "Sum up the world's news of 19 November 2026 in one image" bounty ($250 in USDC).

A newspaper front page: masthead "THE WORLD IN ONE DAY", hero story on the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, plus GTA VI's launch, Anthropic's record $81.3B IPO, the Crimean Bridge struck again, and the ICJ ruling on Myanmar — with an "Also today" strip covering Iran, Voyager 1, the record Van Gogh sale, North Korea and Cyclone Akvan. All five illustrations are original AI art with no text in them; every word on the page is rendered by the browser from HTML, so it stays sharp.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to the output directory. It writes the same bytes on every run.
